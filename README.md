# LegalPundits.com

Plain-English law, free legal tools and a free case review. Static site generated by `build.py` (Python standard library only) and served by GitHub Pages from the `main` branch.

## Structure
- `src/siteconfig.py` — site settings (AdSense client, optional manual ad slot IDs, owner contact link).
- `src/data.py` — practice areas, state deadline data, tools, news feeds, YouTube channels, Global Law Desk.
- `src/content/` — guides, glossary, quiz bank and legal pages.
- `assets/` — CSS, JavaScript (site + tools), images.
- `scripts/update_feeds.py` — pulls legal news and YouTube feeds into `data/*.json`.
- `.github/workflows/auto-refresh.yml` — refreshes content every 6 hours and rebuilds.
- `docs/RESEARCH.md` — 42-site competitive research log. `docs/BUILD-PROMPT.md` — phase-wise build prompt.

## Build locally
```
python scripts/update_feeds.py   # optional: refresh news/videos
python build.py
```

## Add content
- New guide: add a dict to `src/content/guides_a.py` or `guides_b.py`, then run `python build.py`.
- Manual AdSense units: paste slot IDs into `SITE["ad_slots"]` in `src/siteconfig.py`. Empty slots render nothing; Auto ads work from the head script.

## Custom domain
When DNS for legalpundits.com points to GitHub Pages, add the domain under Settings → Pages and commit a `CNAME` file containing `legalpundits.com`. `ads.txt`, `robots.txt` and `sitemap.xml` are already at the root.
