# LegalPundits.com — Phase-Wise Build Prompt

## The winning idea (decision)

**LegalPundits.com = "Plain-English law, free legal calculators, and a free case review."**
A US-first consumer legal-answers hub (with a Global Law Desk for Canada, UK, India, Australia) that:

1. Ranks for the highest-CPC consumer legal intents (accidents/injury, employment, divorce/custody, DUI/criminal, immigration, debt/bankruptcy, landlord-tenant, estate planning, small business/trademarks) with expert-style "pundit" explainers.
2. Converts readers with free interactive tools (settlement estimator, deadline finder, contingency-fee calculator, court-days counter, demand-letter generator, "Do I need a lawyer?" quiz) that hand off to a **Free Case Review** funnel.
3. Monetizes in four layers: **Google AdSense** (base layer on high-CPC legal pages) → **lead generation** (case reviews to vetted attorneys, where lawful) → **attorney network/sponsored listings & advertising** → **supporter donations, sponsorships, contests**.
4. Self-updates every 6 hours (legal news + YouTube explainer feeds) via a GitHub Actions workflow on the free GitHub Pages plan.

Why this beats alternatives (news-only blog, lawyer directory, document shop): news-only earns low RPM and needs daily writers; directories need thousands of listings before they're useful; document shops need payments and liability cover. Calculators + explainers + funnel compound: tools earn links and repeat visits, explainers earn high-CPC ad clicks, and every page routes intent into a lead.

## Phase 0 — Brand, positioning and legal guardrails
- Brand: "LegalPundits" (domain identity only, no trademark claim). Tagline: "Plain-English law. Free tools. Real help."
- Voice: confident, plain English, no jargon without a definition; every guide ends with "When to call a lawyer".
- Mandatory on every page: top banner "Contact, if you are interested in this website/domain name/Sponsorship/Advertisement/Partnership" linked to the owner's contact page; "Not a law firm / not legal advice" footer; links to Disclaimer, Privacy, Terms, Trademark & Copyright Disclosure, Editorial Policy.
- One contact email for every form, never shown in text or HTML; assembled in JavaScript only at submit time and posted through FormSubmit's AJAX endpoint.
- Lead-gen compliance: explicit consent text (shared with independent attorneys; calls/texts; consent not required to buy anything), "may be considered a lawyer referral service in some states" disclosure, Colorado submissions flagged do-not-sell (SB26-174), low-income users pointed to free legal aid.

## Phase 1 — Architecture and hosting
- Static site generated by a dependency-free Python script (`build.py`) from content modules in `src/`; output committed to the repo root so GitHub Pages serves it from the `main` branch.
- Pretty URLs (`/guides/<slug>/`), all links relative so the site works on `webworksa1.github.io/legalpundits-com/` and on the custom domain.
- Files: `ads.txt`, `robots.txt`, `sitemap.xml`, `404.html`, `.nojekyll`, `data/*.json` for runtime widgets.
- Expandability: adding a guide = adding one dict to `src/content/guides.py`; adding a tool = one entry in the tools registry + JS function.

## Phase 2 — Design system
- Editorial-trust aesthetic: ivory paper background, deep ink navy, saffron-gold accent (the "pundit" cue), teal for actions; serif display headings + clean sans body; dark mode.
- Components: contact banner, sticky header with mega-nav and search, hero with issue tiles, cards, stat strips, step lists, FAQ accordions, tool panels, CTA boxes, sticky mobile "Free Case Review" bar, cookie notice, toast confirmations.
- Accessibility: skip link, focus states, labels on every input, 4.5:1 contrast, reduced-motion support.

## Phase 3 — Core content (AdSense approval depends on this)
- 26 in-depth original guides across 10 practice areas, each with: key takeaways, structured sections, FAQ (FAQPage schema), "When to call a lawyer", official sources (.gov, courts, Cornell LII), related tools, last-reviewed date, inline case-review CTA.
- 10 practice-area hubs, 120+ term glossary with live search and Term of the Day, Global Law Desk, Free Legal Aid page.
- Trust pages: About, Editorial Policy, Contact, Disclaimer, Privacy (Google/AdSense cookie disclosure), Terms, Trademark & Copyright Disclosure, Advertising Disclosure.

## Phase 4 — Interactive tools
1. Personal Injury Settlement Estimator (multiplier method, comparative fault, policy limit, fee-adjusted net).
2. Statute of Limitations Deadline Finder (50 states + DC, personal injury; computes the date and days left).
3. Contingency Fee & Net Recovery Calculator.
4. Court Deadline (Calendar/Business Days) Calculator with US federal holidays and weekend roll-forward.
5. Demand Letter Generator (unpaid debt, security deposit, property damage, refund) with copy/print.
6. "Do I Need a Lawyer?" quiz scoring urgency → prefilled case review.
7. Legal IQ daily quiz and glossary search (engagement + return visits).

## Phase 5 — Lead generation engine (dedicated, high-converting)
- `/case-review/`: 5-step form (issue → state → timing & urgency → what happened → contact + consent), progress bar, honeypot, inline validation, thank-you state with next steps.
- Entry points everywhere: hero CTA, sticky mobile bar, inline CTA in every guide, tool results hand-off with prefilled fields, scroll-triggered (non-blocking) slide-in on guides.
- `/ask/` free question form, `/attorneys/` attorney-network signup (B2B lead source), `/advertise/` sponsorship enquiries.

## Phase 6 — Monetization stack
- AdSense script in every page `<head>` (Auto ads). Optional manual slots switch on by adding slot IDs to `src/site.py`; empty slots render nothing (no blank boxes before approval).
- YouTube: channel playlists embedded with the uploads-playlist technique; refreshed by the workflow.
- `/support/` donations: tiers mapped to Operations, Promotions & Marketing, Hiring Talent, Contests & Prizes; pledge form; sponsorship packages.
- `/contests/`: monthly Pundit Challenge (essay, explainer video, quiz), prizes, official rules, entry form.
- `/careers/`: writers, attorney reviewers, paralegal researchers, video editors, campus ambassadors; application form.

## Phase 7 — Automation
- `scripts/update_feeds.py` pulls RSS/Atom from legal publishers and YouTube channel feeds (stdlib only), dedupes, sorts, writes `data/news.json` and `data/videos.json`.
- `.github/workflows/auto-refresh.yml` runs every 6 hours + manual trigger: update feeds → rebuild → commit if changed → request a Pages build.
- Client-side freshness: news widget re-reads `data/news.json`; Term of the Day and daily quiz rotate by date.

## Phase 8 — SEO and performance
- Unique titles/descriptions, canonical URLs, Open Graph, JSON-LD (Organization, WebSite+SearchAction, Article, FAQPage, BreadcrumbList), XML sitemap, internal links hub↔guide↔tool.
- No frameworks, one CSS file, deferred JS, system-font fallback; lazy-loaded embeds.

## Phase 9 — Launch checklist
1. Point `legalpundits.com` DNS to GitHub Pages and add the custom domain in repo Settings → Pages (then add a `CNAME` file).
2. Submit the domain in AdSense; `ads.txt` is already at the root. Enable AdSense "Privacy & messaging" (Google-certified consent for EEA/UK).
3. Activate FormSubmit by confirming the first submission email.
4. Verify Search Console, submit `sitemap.xml`.
5. Sign attorney partners per state before routing leads; keep Colorado do-not-sell.

## Phase 10 — Growth roadmap
State-by-state pages for each guide (50× content multiplier), Spanish and Hindi editions, attorney profiles with sponsored placement, newsletter sponsorships, AI-assisted Q&A answered by reviewed pundits.
